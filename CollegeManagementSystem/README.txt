COLLEGE MANAGEMENT SYSTEM - ECLIPSE + JAVA + MYSQL

1. Create/import a Java project named CollegeManagementSystem.
2. Create package: college.management
3. Put all .java files into src/college/management/
4. Run college_management.sql in MySQL Workbench.
5. Install MySQL Connector/J.
6. In Eclipse:
   Project > Build Path > Configure Build Path > Libraries
   > Add External JARs > mysql-connector-j-*.jar
7. Open DBConnection.java.
8. Set USER and PASSWORD to your MySQL credentials.
9. Run Login.java.
